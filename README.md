# Poppel Support Site

This folder is a standalone static support website. It can be published for free with GitHub Pages.

## Before publishing

Replace these placeholders in `index.html`, `privacy.html`, and `terms.html`:

- The support email is set to `MonarchDevelopmentSupport@gmail.com`.
- The copyright owner is set to Dale Tollman.

## Publish with GitHub Pages

1. Create a GitHub repository named `poppel-support`.
2. Upload the contents of this `support-site` folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, then select `main` and `/ (root)`.
5. GitHub will provide a free public URL, typically `https://YOUR-GITHUB-USERNAME.github.io/poppel-support/`.

Use that address in App Store Connect:

- Support URL: `https://YOUR-GITHUB-USERNAME.github.io/poppel-support/`
- Privacy Policy URL: `https://YOUR-GITHUB-USERNAME.github.io/poppel-support/privacy.html`
- Marketing URL: optional; leave blank if you do not want one.

You can add a custom domain later, but it is not required.
